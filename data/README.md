# Data access

No original participant recordings are included in this public code release. The local working materials include named folders, spreadsheets, acquisition images, downloaded database MAT files, Origin projects, and intermediate outputs. These have not been cleared for redistribution or verified as anonymized.

The supplied collection contains files labeled `DB3_s1` and `DB3_s2`, but an authoritative source/version/license mapping has not been established. Do not infer redistribution permission from these filenames. Retrieve third-party data from its original source after verifying the dataset identity and applicable terms.

Use `examples/demo_joint_sparse.m` without any external data. This generates synthetic mathematical signals at runtime, not human EMG recordings.

For real-data reproduction, contact the maintainer through a GitHub issue. Availability is subject to data-owner permission and applicable consent; access is not guaranteed. Keep local raw data ignored by Git and report only approved anonymized results.
